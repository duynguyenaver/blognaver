Đồng bộ quota Codex

Nhập phản hồi account/rateLimits/read từ Codex App Server, hoặc dữ liệu tóm tắt bạn đọc trong /status.

Local-only
Cách lấy số liệu: Trong Codex CLI gõ /status hoặc kiểm tra Settings → Usage. Nếu dùng Codex App Server, phương thức account/rateLimits/read trả về usedPercent, windowDurationMins, resetsAt. Chỉ dán phần rateLimits, tuyệt đối không dán auth token.

Đồng bộ thực từ Codex CLI trên máy Mac

Không cần sao chép token hay nhập quota bằng tay. Dữ liệu lấy từ Codex App Server chạy trên Mac của bạn.
