Dữ liệu mới đồng bộ sẽ được mã hóa AES-256-GCM trước khi tải lên GitHub. Repository vẫn công khai. Mã PIN 4 số có thể bị dò ngoại tuyến; nên sử dụng mật khẩu dài, riêng biệt để bảo vệ thông tin nhạy cảm. Nếu từng đồng bộ bản rõ trước đây, lịch sử Git có thể vẫn chứa dữ liệu đó.

Quên mã / Đặt mã mới ▾

Mã mới chỉ mã hóa các bản ghi đang có trong phiên này. Bản mã local cũ được sao lưu trước khi thay thế. Không cần kết nối GitHub; bản sao GitHub chưa bị thay đổi.

Lưu trên máy ngay sau thao tác. Chỉ sao lưu GitHub khi bạn bấm Đồng bộ.

Tải từ GitHub yêu cầu nhập đúng mã mở khóa. Dữ liệu chỉ được giải mã trong trình duyệt. Không lưu mã mở khóa vào repository hoặc bộ nhớ trình duyệt. Nếu đã từng tải dữ liệu điểm danh dạng rõ lên GitHub, cần xử lý riêng lịch sử commit để loại bỏ dữ liệu cũ.
