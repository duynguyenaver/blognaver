Cách bật cầu nối (chỉ khi chưa kết nối)

Đặt API key mới trong biến môi trường của Terminal trên máy Mac, sau đó bật cầu nối. Không dán API key vào blog hoặc GitHub.

cd ~/Desktop/blognaver
read -s "GEMINI_API_KEY?Nhập Gemini API key mới: "
echo
export GEMINI_API_KEY
python3 scripts/gemini-quota-bridge.py

Dùng trên cùng Mac, giữ Terminal mở. Cầu nối chỉ lắng nghe 127.0.0.1:19475. Nếu key cũ đã chia sẻ, hãy thu hồi và tạo key mới trước khi sử dụng.

Theo dõi quota thực

Google áp dụng hạn mức theo model và theo dự án: yêu cầu mỗi phút (RPM), token mỗi phút (TPM), yêu cầu mỗi ngày (RPD). Hạn mức và mức sử dụng chính xác xem bằng tài khoản Google sở hữu dự án.
